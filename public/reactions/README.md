# Медиа для реакций

Сейчас все реакции текстовые. Настоящих анимаций в проекте нет; статичные изображения не подставляются вместо них.

1. Добавьте сюда свою анимацию взрослой модели (25+), с правами на использование. Эстетика: fashion editorial / Y2K, улыбка, подмигивание, воздушный поцелуй, ироничный взгляд; без наготы. Если снимается верхний слой, под ним остаётся непрозрачный закрытый топ.
2. В `lib/reactions.ts` найдите сочетание `event` + `audience` и измените `mediaPath: null` на путь, например `/reactions/right-on-time.webm`.
3. Поддерживаются `.gif`, анимированный `.webp`, `.mp4`, `.webm`. Не добавляйте статичный WebP под видом анимации: определение движения остаётся ответственностью автора файла.
4. Рекомендуется короткий клип 2–4 секунды, до 2 MB, без аудиодорожки. Видео всегда воспроизводится muted/playsInline, без controls. Желательно MP4 H.264 или WebM VP9 для совместимости.
5. `durationMs` задаёт срок показа; компонент ограничивает его диапазоном 2000–4000 мс. Необходимое медиа загружается только при показе; остальные файлы не предзагружаются. При ошибке загрузки или воспроизведения остаётся текст. При `prefers-reduced-motion` медиа не загружается и показывается только текст.

Каждая запись содержит точный текст, аудиторию, событие, локальный путь и длительность. Для добавления/замены медиа и изменения оформления конкретной реакции достаточно конфигурации и файлов. Новая категория бизнес-событий требует явного сопоставления существующей операции/уведомления, а не имитации события.
