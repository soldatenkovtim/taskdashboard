# Нуарные реакции

Вторая версия использует одну героиню: исходный кадр `assets/reactions/v2/character-reference.png` передаётся встроенному imagegen в каждой генерации. Чёрно-белый нуар и красная помада сохранены.

Каждая новая GIF — 24 сгенерированных последовательных кадра, цикл 4,1 секунды без звука. Поп-ап показывается 4,5 секунды. Это покадровая анимация, не видеосъёмка. Подписи, аудитории и условия срабатывания остаются в `lib/reactions.ts` без изменений.

Просмотр десяти подключённых реакций: `/reactions`. Кнопки запускают настоящий поп-ап, не создавая задач и уведомлений. Дизайн галереи сохранён.

Исходники и точные запросы: `assets/reactions/v2/manifest.json`. Пересборка: `node scripts/build-reactions-v2.mjs`. Результаты: `public/reactions/v2/`. Файлы `*-poster.webp` — статичные обложки, не анимации. Первая версия сохранена отдельно и собирается старым скриптом `scripts/build-reactions.mjs`.

Дополнительная WHAT A GOOD BOSS подготовлена отдельным файлом, без добавления события «очередь разобрана»: это потребовало бы изменения логики запуска, которое запрещено текущим заданием.

При выключенных реакциях они не показываются. При `prefers-reduced-motion` GIF не загружаются, остаётся текст. При ошибке загрузки также показывается текст. Загружается только текущая реакция.
