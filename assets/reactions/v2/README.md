# Реакции: единая героиня

`character-reference.png` — первый кадр ранее созданной GOOD JOB, BABY, без изменения лица. Каждый вызов встроенного imagegen получает именно этот файл как reference image. Исходные материалы первой версии сохраняются уровнем выше.

`manifest.json` сохраняет точные запросы и параметры сборки. Каждый лист содержит 24 последовательных кадра: 6 колонок × 4 строки, порядок слева направо, затем следующая строка. Это покадровая GIF-анимация, не видеосъёмка и не генерация внешним видеосервисом.

Сборка: `node scripts/build-reactions-v2.mjs`.

Проверка перед подключением: сетка соответствует параметрам, одна узнаваемая героиня, действие следует сценарию, руки и одежда движутся последовательно, лицо выразительно, красный топ на бретелях в тон губам в RIGHT ON TIME остаётся непрозрачным на всех кадрах. Автоматические проверки наличия разных кадров не заменяют визуальную проверку.

WHAT A GOOD BOSS подготовлена как отдельная сцена. Она не привязана к новому событию: по заданию сохраняются существующие условия показа и десять реакций в галерее.
